## 2. Findings Addressed by This Run

This run re-verified the fixes for the three findings from the 2026-09-30
verification of PR #9146:

1. **Concurrent HCPEtcdBackup check-then-create race** (TC-005): fixed by a
   quorum read (`mgr.GetAPIReader()`) in job discovery, skipping the backup's
   own Job and treating Jobs without terminal conditions as active.
   Previously both concurrent backups could pass the check simultaneously;
   now the second is terminally rejected with the active Job named.
2. **Failed named-shard restore not surfaced** (TC-008, TC-009): fixed by
   readiness-independent inspection of init-container termination states in
   `etcdRestoredConditionForSTS` and non-short-circuiting aggregation. A
   failing shard now publishes `EtcdSnapshotRestored=False` naming the shard
   while the STS is not ready, and the condition correctly flips to True on
   recovery.
3. **Version-skew CPO image propagation** (TC-004): fixed by mirroring the
   `hypershift.openshift.io/control-plane-operator-image` annotation from HC
   to HCP; backup Jobs now use the deployed CPO override image and support
   `--snapshot-dir`.

## 4. Notes and Caveats

- **Fixes uncommitted:** the three fix commits were uncommitted in the
  working tree at verification time; the override image contains them but
  they must be pushed for CI and final review.
- **OADp:** untested due to catalog availability (1.5.8 max); requires a
  follow-up run on a cluster with OADp 1.6+.
- **Cross-cluster secret restore:** secrets are encrypted with the guest's
  per-cluster `etcd-encryption-key`; restoring a snapshot into a *new*
  cluster requires porting the source cluster's key Secret (standard DR
  step). Without it, reads fail with "no matching key was found for the
  provided AES transformer" — expected, not a restore defect.
- **Payload konnectivity skew:** with a 4.22 payload and newer CPO override,
  the KAS konnectivity container crash-loops and the HC never reports
  `Available`; etcd functionality is unaffected. Verified via HCP conditions
  and management-cluster port-forward (`oc port-forward svc/kube-apiserver`
  with a rewritten kubeconfig — the guest external LB DNS does not resolve).
- **Cosmetic:** HCP condition messages for failed restores include curl
  progress-meter output (etcd-init.sh writes stderr to the termination
  message). Follow-up suggested, not blocking.
- Etcd key prefix in HyperShift is `/kubernetes.io` (not `/registry`);
  `etcdctl --prefix` with a non-slash-leading key silently returns nothing.

## 5. Recommendation

All functional scenarios pass. Merge readiness for the three fix commits is
supported by this verification, contingent on: (a) the fixes being committed
and passing CI, and (b) a follow-up OADp 1.6+ validation when the catalog
provides it.
