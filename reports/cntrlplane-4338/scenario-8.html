TC-CA-001. Live CA selection, rotation, removal and restoration

pass

Distinct valid CA sources A/B projected correctly; stale copies were removed; workers and connectivity recovered after every change.

Objective

Exercise CA lifecycle through the supported HC path while preserving source data and independent connectivity.

Preconditions

  • Baseline has no HTTP(S) proxy or custom trustedCA dependency; public system trust and the original API CA remain available.
  • Two workers, Replace policy, SingleReplica control plane. Readiness timeout: 2,100 seconds per phase; projection bound: 600 seconds.
  • Cleanup registered before reference changes; test sources created only in HC namespace, never pre-populated in HCP namespace.

Execution

  1. Capture baseline configuration, readiness and API/outbound HTTPS; create valid distinguishable CA sources A/B.
  2. Select A; wait for operator-created HCP copy, named guest copy and user bundle; complete worker rollout and connectivity checks.
  3. Rotate to B; verify B's data, stale A-copy removal and unchanged HC sources; complete worker and connectivity gates.
  4. Remove reference; verify user/stale-copy cleanup while sources remain; complete readiness and connectivity gates.
  5. Restore original configuration and baseline worker hash, recheck connectivity, then delete unreferenced test sources.
